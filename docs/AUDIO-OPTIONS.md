# Audio options to listen to and choose from

A shortlist of free music and sounds for Corner Lands. Every option has an ID: pick by ID
(e.g. "M3, P15, S-cow-2") and the chosen files get wired into the game and listed in
`CREDITS.md`.

**About the licences.** They were gathered from each page's listing via search, because the
pages themselves could not be opened from the build machine. Before a file goes in the game,
glance at its licence box once (10 seconds) and note it in `CREDITS.md`.

- **CC0 / PD**: free, no credit needed (a thank-you in the credits is still nice).
- **CC BY**: free, credit the author in the game's credits.
- **CC BY-SA**: free, credit; an *edited* file (cut, looped) must stay CC BY-SA. Fine to use, slightly more bookkeeping.
- **?** = licence only partly seen, or conflicting: check it before choosing.
- Avoided everywhere: NC (non-commercial), ND (no changes), "personal use only", YouTube rips.

- [Kenney audio](https://kenney.nl/assets/category:Audio): CC0 packs.
